# Environment and Setup Information

## Known Working Environment

The project was successfully developed and tested using:

- Operating System: Windows
- Linux Environment: WSL2
- Distribution: Ubuntu 26.04.1 LTS
- CMake: 4.2.3
- OpenCV: 4.10.0
- GCC/G++: C++ compiler available through Ubuntu
- Python: Python 3
- Git: Git

## Required Environment

The project requires:

- WSL2 or a compatible Linux environment
- Ubuntu/Linux
- GCC/G++
- CMake 4.x
- OpenCV 4.x
- Python 3
- Git

## OpenCV Compatibility

The project was tested successfully with OpenCV 4.10.0.

OpenCV 4.x is recommended for this implementation.

OpenCV 5.x is not recommended because the original Udacity implementation contains APIs that are not compatible with OpenCV 5.x.

## Large External Files

The following files are intentionally not stored in the GitHub repository:

- KITTI dataset
- YOLOv3 weights
- Generated result frames
- CMake build files

These files must be obtained/generated separately according to the instructions in README.md.
